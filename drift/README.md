# Registro drift

Una voce per ogni divergenza fra quello che i documenti dicono e quello che il sistema fa.
Il registro nasce **vuoto**: si riempie quando una divergenza viene trovata.

| Campo | Significato |
|---|---|
| **Severita'** | LOW, MEDIUM, HIGH |
| **Documento dice** | cosa promette il documento |
| **Realta' dice** | cosa fa il sistema, misurato |
| **Causa** | perche' e' successo |
| **Chi l'ha trovato** | chi se n'e' accorto |
| **Rischio** | cosa puo' costare |
| **Stato** | OPEN, FIXED, ACCEPTED |
| **Chiuso** | data di chiusura, se chiusa |
| **Decisione** | DEC-xxxx che la chiude, se accettata |
| **Evidenza** | il comando o il file che lo prova |

## Voci

Nessuna voce registrata.
